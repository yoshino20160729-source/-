STM32介绍和按键点灯
小任务：
- 根据所学GPIO的工作方式，能够通过按键A控制LED的亮灭
模式一：按下按键一次，LED实现状态翻转（亮 ↔ 灭），
模式二：按下按键时LED 常亮，松开时LED 熄灭，
按键B实现两种模式的切换。
验收要求：
- 按键要实现软件消抖，方式不限(阻塞式或非阻塞式)
外部中断和定时器简单学习
小任务：
任意设计外部信号，频率要求低于1Hz，接收外部信号后发生中断事件，并有肉眼可观察的特定现象发生。
任意设计定时任务，频率要求低于1Hz，可以随时调整三种不同频率触发定时中断，并有肉眼可观察的特定现象发生。
验收要求：
特定现象能够准确无误地在中断事件发生时发生，并注意特定现象发生后应在下一次中断事件发生前消除。
PWM电机控制和速度读取
小任务：
根据所学知识，使用单片机发送PWM波控制电机，要求能够使电机正常转动，并且能够通过调试模式读取到电机转速。
验收要求：
视频展示电机能实现正转和反转，能在keil，cubeide或其他开发平台的调试模式下看到电机速度。
增量式、位置式和串级PID算法
小任务：
根据本次pid培训内容，结合前几次培训所学知识，实现通过按键改变电机速度，要求电机速度1rps（圈每秒），2rps，3rps三档可调。
